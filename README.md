# Phishing Website Detection Using Machine Learning

## Project Overview
Phishing Website Detection is a machine learning-based web application designed to identify potentially malicious websites by analyzing URL features.

The system helps users distinguish between legitimate and phishing websites.

## Technologies Used
- Python
- Flask
- Machine Learning
- HTML
- CSS
- JavaScript
- Pandas
- Scikit-learn

## Key Features
- URL-based phishing website detection
- Machine learning-based prediction
- Feature extraction from URLs
- User-friendly web interface
- Flask backend integration

## How to Run the Project

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install dependencies
```bash
cd backend
pip install -r requirements.txt
```

### 3. Run the Flask application
```bash
python app.py
```

### 4. Open the frontend
Open `frontend/index.html` in your browser.

## Project Objective
To develop a machine learning-based solution that helps identify phishing websites and improve awareness of malicious URLs.
